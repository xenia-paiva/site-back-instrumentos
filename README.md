# Back Instrumentos

Site de uma loja de instrumentos musicais desenvolvido durante meus estudos de HTML e CSS.

## Sobre o projeto

O projeto apresenta uma loja fictícia de instrumentos musicais, com páginas para apresentação da empresa, instrumentos disponíveis e contato.

## Tecnologias utilizadas

- HTML5
- CSS3
- Imagens responsivas
- Visual Studio Code
- Git e GitHub

## Páginas

- Página inicial
- Instrumentos
- Sobre
- Contato

## Objetivo

Praticar a criação e organização de páginas web, navegação entre páginas e utilização de imagens responsivas.
